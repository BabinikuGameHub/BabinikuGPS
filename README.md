## 기획 배경: 코어 루프가 통째로 바뀐 프로젝트

원래는 걸음 수를 재는 **만보기 게임**으로 기획을 시작했습니다. 그런데 Unity로 만든 모바일 앱이 백그라운드에서 실행되지 않아, 앱을 꺼둔 상태에서 걸음 수를 셀 방법이 없다는 걸 개발 중에 알게 됐습니다. 우회 방법을 찾아봤지만 결국 코어 메커닉 자체가 이 전제로는 성립하지 않는다고 판단했습니다.

그래서 "걸음 수"라는 전제를 버리고, **이동 중 찍은 세 지점의 GPS 좌표로 삼각형을 만들고 그 면적을 점수로 쓰는 방식**으로 코어를 다시 설계해 제안했습니다. 걸음 수는 "얼마나 걸었는지"만 재지만, 삼각형 면적은 "얼마나 넓게 돌아다녔는지"를 잽니다. 같은 이동량이라도 좁은 반경을 왕복하는 것보다 넓게 도는 편이 더 높은 점수를 받도록 유도가 바뀝니다.

## 핵심 구현

### GPS → Unity 좌표 변환

Mapbox Unity SDK를 연동해 실제 GPS 좌표를 Unity 씬 좌표로 변환하는 파이프라인을 구성했습니다. 플레이어의 이동 경로에서 세 지점을 샘플링해 삼각형 넓이를 계산하는 방식입니다.

### 보상 공식

```
보상 = (기본면적 + 덧셈보정치) × 곱셈보정치
```

면적(플레이 성과)을 그대로 보상으로 쓰지 않고, 덧셈·곱셈 보정치를 둬서 완급을 조절할 수 있게 설계했습니다.

### 등급별 확률 로직

보상 등급은 90% / 9% / 1% 확률 구간으로 나눠 설계했습니다. 대부분의 플레이에서 기본적인 보상을 받되, 낮은 확률로 더 높은 등급의 보상이 나오는 구조입니다.
